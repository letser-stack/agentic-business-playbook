# 智能体小生意方法论（小白版）

> 根据 Alex Finn 的视频《Grok Bot 帮我搭了个全自动生意，已经赚了 $1,100》整理（中文双语版由 @SUOHA_AI 转发）。
> 所有说法都标了视频时间戳 `[分:秒]`，方便你回去对照。凡是视频里没说的，我会明确写"这是我的建议"。

---

## 1. 一句话核心

**找一个"简单的小问题"，让一个 AI Bot 当"CEO"帮你把网站做出来、每天自动维护，你只负责发帖引流和拍板收钱的事。**

打个比方：你开了一家小店，雇了一个不睡觉的店长（Bot）。店长自己进货、打扫、发传单、记账；你每周看一眼报表，偶尔点头说"行"。

## 3. 方法论：可复用的 6 步框架

每一步都按 **是什么 / 为什么 / 怎么做 / 检查清单** 来写。

### 第 1 步：任命 CEO Bot
- **是什么**：新建一个只负责这门生意的 Bot，给它名字和"CEO"头衔。[02:38–03:22]
- **为什么**：像给店长发工牌——它知道"这家店归我管"，会自己拆任务、排日程，不用你天天催。
- **怎么做**：Grok Bot 里新建 Bot → 建一个分类 → 起名 → 发一句"你叫 XX，你是我新生意的 CEO"。
- **检查清单**
  - [ ] 这个 Bot 只管这一件事（不和别的事混用）
  - [ ] 名字、CEO 角色已设定，Bot 回复确认了

### 第 2 步：选题（找一个简单的小问题）
- **是什么**：让 Bot 帮你想点子，你从里面挑一个。[03:29–07:43]
- **为什么**：作者说"最好的生意是解决问题的生意"，而且要简单到 Bot 能全包。[03:35–04:05] 就像摆小摊：卖一种东西、卖清楚，比开超市容易。
- **怎么做**：把"想点子"提示词（第 4 节）发给 Bot，写上你懂的领域；Bot 给选项后挑一个，并说清楚"谁会付钱"（他的答案：厂商买置顶赞助位）[07:23–07:43]。
- **检查清单**
  - [ ] 一句话能说清"帮谁解决什么问题"
  - [ ] 知道钱从谁那里来
  - [ ] 不纠结名字，"行动优先" [07:47–08:22]

### 第 3 步：建站（先上线，再变好看）
- **是什么**：让 Bot 直接把第一版网站做出来并上线。[08:22–09:14]
- **为什么**：作者强调要尽快"放到网上，让其他 AI 能找到并推荐它"。[08:17–08:22] 先开门营业，装修以后再说。
- **怎么做**：回复 Bot "直接做吧"。视频里 Bot 用内置的 Cursor 云端代理约 2 分钟做好第一版。[08:31–08:41]
- **检查清单**
  - [ ] 网站能打开
  - [ ] 内容是真的（视频里是 33 个真实工具）[09:09–09:14]
  - [ ] 不追求一开始就漂亮

### 第 4 步：定常规任务（routines）
- **是什么**：给 Bot 一份"长期职责清单"，让它自己建定时任务。[09:14–11:50]
- **为什么**：这是从"一次性建站"变成"自动经营"的关键；作者说做完这步，人工活基本就干完了。[09:19–09:26]
- **怎么做**：发"职责清单"提示词（第 4 节）。视频里 Bot 自动建好：每天早上加内容 + 查 Bug + 看 X 反馈 + 做一处 SEO；每周一发进度报告；**涉及发邮件、赞助、账单、付款先问你**。[11:26–11:50]
- **检查清单**
  - [ ] 有每日任务
  - [ ] 有每周汇报
  - [ ] 有"花钱/对外发东西前先问我"的规矩（很重要，见第 5 节）

### 第 5 步：接工具（Vercel / GitHub / Resend / Stripe）
- **是什么**：给 Bot 接上 4 个"插座"。[13:05–14:33]、[16:22–17:00]
- **为什么**：没有这些，Bot 只能"说"，不能"做"。好比店长需要店面钥匙、仓库、喇叭和收银机。

| 工具 | 比喻 | 视频里的用途 |
|---|---|---|
| Vercel | 店面 | 托管网站，可免费 [13:08–13:34] |
| GitHub | 仓库 | 存代码，Bot 能推改动和 PR [13:34–13:44] |
| Resend | 喇叭 | 收邮箱、每天自动发周刊、统计打开和点击 [13:44–14:18] |
| Stripe | 收银机 | Bot 自动生成付款链接放进赞助区 [16:22–16:55] |

- **检查清单**
  - [ ] 4 个连接都已授权
  - [ ] 网站上有邮箱订阅框
  - [ ] 赞助区有 Stripe 付款链接

### 第 6 步：获取流量（你本人最该做的事）
- **是什么**：自己在社交媒体发帖，偶尔带上网站链接。[14:39–16:22]
- **为什么**：作者原话大意："软件快没护城河了，分发（流量）是最后的护城河之一。"[14:46–15:13] 店再好，没人路过也没生意。
- **怎么做**：开个 X 账号，多回复别人，每天发帖（他当年每天 2 条）[15:59–16:10]；不用大号，"50 个粉丝就能开始"[15:24–15:29]。
- **检查清单**
  - [ ] 有一个固定发帖的账号
  - [ ] 每天至少发 1–2 条
  - [ ] 每隔几条提一次自己的网站

## 4. 关键提示词 / 话术（视频原话 + 中文意思）

> 英文是自动转写，可能有小错字；中文是意思翻译。

**① 任命 CEO** [03:02–03:13]
> "Your name is Timothy and I want you to be the CEO of a new agentic business I want to build."
> 你叫 Timothy，我要你当我想做的新智能体生意的 CEO。

**② 想点子** [04:12–04:26]
> "I want you to design, build and run an autonomous business for me. Let's first come up with the idea. I want this to be a very simple problem my audience might have. I'm into AI agents, tech, video games and vibe coding. What are some very simple challenges we can solve?"
> 帮我设计、搭建并运营一个自动化生意。先想点子：要解决我受众的一个很简单的问题。我关注 AI 智能体、科技、游戏、vibe coding。有哪些很简单的问题可以解决？

**③ 拍板方向** [06:50–07:13]（大意）
> "Let's do AI tool ranking… a directory of AI tools that shows which AI tools people should be using for which use cases and showcases new tool releases."
> 就做 AI 工具排行：按用途列出该用哪些工具，并展示新发布的工具。

**④ 行动优先** [08:07–08:22]（大意）
> "Let's just build it… have a bias for action… it doesn't need to be perfect."
> 直接做，行动优先，不需要完美。

**⑤ 交代长期职责** [10:30–10:48]
> "You are going to be the autonomous CEO for this micro business. Here is everything I want you to work on and maintain for me:" + 清单
> 你是这个小生意的自主 CEO，以下是我要你负责并维护的所有事项：

清单内容（视频 [09:46–10:22] 屏幕/口述）：适时变现、优化 SEO、优化让聊天机器人能推荐、创建并维护邮件周刊、盯 X 上的反馈、盯 Bug。

## 5. 常见坑和风险（说实话版）

1. **$1,100 是作者自己说的，没有被独立验证。** 视频里展示的是他自己的 Stripe 页面 [00:36–00:46]；而且这些钱来自 2 笔赞助 [04:35]，不是稳定的月收入。
2. **作者有大号流量。** 他自己说有约 50 万粉丝 [15:15–15:20, 16:06–16:10]，经常发帖给站点导流。普通人起步流量会慢很多，"50 个粉丝就能开始"是他的说法，不是保证。
3. **"零工作量"说得太满。** 视频里他还是要：选题、拍板、接 4 个工具、给真名和联系邮箱、接 Google Search Console [18:44–18:58]、自己发帖引流。
4. **"每个生意 1–2 万美元"是愿景，不是数据。** [17:46–17:58]
5. **视频本身也在推广。** 作者在视频里推广自己的频道、周刊和网站 [12:22–12:53, 20:01–20:06]，看待数字要带点保留。
6. **钱和对外发信一定要设"先问我"。** 视频里的 Bot 规定发邮件/赞助/账单/付款前先确认 [11:42–11:50]——你也要这样设，避免 Bot 乱收费、乱发邮件。
7. **抄写容易，护城河难。** 作者自己说软件很容易被复制 [14:53–15:03]；目录站这类点子谁都能做，赢在坚持更新和引流。
8. **（我的建议）合规。** 收款、邮件营销要遵守平台规则和当地法律（例如邮件要有退订）；Bot 写的内容要你抽查，别出现虚假承诺。

## 6. 套用到 Lester 的「中国工厂代理人」页面：7 天行动清单

你的页面：https://letser-stack.github.io/china-factory-agent/
现状：3C 消费电子选品/验货/售后 + 新品开发；按天 $72 / 包月 $1,680；已有刷卡支付、BNB 和咨询表单；托管在 GitHub Pages。

> 和视频的区别：视频是"赞助型目录站"，你是"卖服务"。所以套用的重点是**让 Bot 帮你持续产出内容、引流、跟进咨询**，而不是指望它替你验货。以下是按视频框架改编的建议，不是视频原话。

| 天 | 做什么 | 对应视频步骤 | 完成标准 |
|---|---|---|---|
| 第 1 天 | 新建一个 Bot，起名（如"工厂通"），设为"中国工厂代理生意的 CEO"。把你的页面链接和服务价格告诉它。 | 第 1 步 | Bot 能复述你的服务和价格 |
| 第 2 天 | 用"想点子"提示词，但改成：「我做 3C 消费电子的中国工厂对接，客户是海外小卖家。他们有哪些很简单的问题，我可以用一个免费小网页/目录解决来吸引咨询？」挑 1 个（例如"3C 品类验货清单"或"深圳 3C 工厂找法指南"）。 | 第 2 步 | 一句话写出"帮谁解决什么问题、怎么带来咨询" |
| 第 3 天 | 让 Bot 在你现有 GitHub 仓库里加这个免费内容页（行动优先，先上线）。 | 第 3 步 + GitHub | 新页面能打开，链接回咨询表单 |
| 第 4 天 | 发"职责清单"提示词：每天做一处 SEO 改进、让 AI 聊天机器人能读懂（加一页清楚的服务说明/FAQ）、查死链和表单是否正常、每周一给我汇报；**发邮件、改价格、收款前必须先问我**。 | 第 4 步 | Bot 建好每日 + 每周任务 |
| 第 5 天 | 接工具：GitHub（已有）；Stripe 检查付款链接正常；可选 Resend 做"每月 3C 供应链小报"收邮箱。是否迁到 Vercel 可问 Bot（GitHub Pages 目前也能用）。 | 第 5 步 | 付款链接测试可用；有订阅框（若选做） |
| 第 6 天 | 在 X 开始发帖：每天 1–2 条 3C 选品/验货小经验，第 3 条左右带一次页面链接；多回复做跨境的人。 | 第 6 步 | 发出至少 2 条，回复 5 条 |
| 第 7 天 | 看 Bot 的第一份汇报：访客、咨询数、问题。选 1 个改进点让 Bot 去做；接 Google Search Console（视频里 Bot 也建议了 [18:52–18:58]）。 | 复盘 | 有数据、有下周 1 个目标 |

**提醒**：服务型生意的"成交"最终还得你本人聊、你本人对接工厂。Bot 能当"前台和宣传员"，当不了"验货员"。
